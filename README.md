# راهنمای نصب اپلیکیشن روی صفحه اصلی گوشی

## 📱 برای اندروید (Chrome):

1. صفحه را در مرورگر Chrome باز کنید
2. روی منوی سه‌نقطه (⋮) ضربه بزنید
3. گزینه **"Add to Home screen"** یا **"افزودن به صفحه اصلی"** را انتخاب کنید
4. نام اپلیکیشن را تأیید کرده و **"Add"** را بزنید

## 🍎 برای آیفون (Safari):

1. صفحه را در مرورگر Safari باز کنید
2. روی دکمه Share (مربع با فلش رو به بالا) ضربه بزنید
3. گزینه **"Add to Home Screen"** را انتخاب کنید
4. در گوشه بالا راست، **"Add"** را بزنید

## ✨ ویژگی‌ها:

- کارکرد آفلاین (با Service Worker)
- حالت تمام‌صفحه در موبایل
- آیکون سفارشی
- تجربه مشابه اپلیکیشن بومی

## 📝 نکته مهم:

برای اینکه قابلیت "Add to Home Screen" کار کند:
- سایت باید با HTTPS سرو شود (یا localhost برای تست)
- فایل manifest.json باید وجود داشته باشد
- Service Worker باید ثبت شود

## 🚀 اجرا:

فایل‌ها را روی یک سرور HTTPS قرار دهید یا از localhost استفاده کنید.
