## 📖 حساب‌وکتاب چیست؟

**حساب‌وکتاب** یک وب‌اپلیکیشن مدیریت مالی شخصی است که به‌طور کامل داخل مرورگر اجرا می‌شود — بدون سرور، بدون دیتابیس، بدون نیاز به اینترنت. تمام داده‌ها فقط در مرورگر خودِ شما ذخیره می‌شوند و هرگز به هیچ سروری ارسال نمی‌شوند.

> ✨ تقویم شمسی (جلالی) به‌صورت الگوریتمی داخل خودِ برنامه پیاده‌سازی شده — بدون هیچ کتابخانهٔ خارجی.

---

## ✨ امکانات

### 🎨 طراحی و تجربهٔ کاربری
- **سیستم طراحی توکن‌محور:** رنگ، سطح، شعاع، فاصله، اندازهٔ قلم، ارتفاع و حرکت همه در توکن‌های CSS تعریف شده‌اند — تم روشن فقط مقدار توکن را عوض می‌کند، نه قواعد کامپوننت
- **سطح‌های تونال به‌جای خط‌کشی:** کارت‌ها بدون حاشیه‌اند و عمق با پلهٔ رنگی و سایهٔ دولایه خوانده می‌شود
- **ارقام فارسی هم‌عرض:** مبالغ با `tabular-nums` و Vazirmatn 700 — ستون‌های عدد دقیقاً زیر هم می‌نشینند
- **کنتراست AA** در هر دو تم، هدف لمسی ۴۴px، حلقهٔ فوکوس با کیبورد، و احترام به `prefers-reduced-motion`
- **RTL کامل:** ترازهای منطقی (`start/end`)، نوارهای پرشونده در جهت درست، و بدون فاصله‌گذاری روی خط فارسی
- **شیت پایینی** برای فرم‌ها در موبایل، **شبکهٔ Bento** در داشبورد، و گذار نرم بین بخش‌ها
- **آیکون SVG درون‌خطی** برای نوار ابزار؛ ایموجی فقط برای دسته‌ها (که خودتان می‌سازید)
- بدون فریمورک، بدون CDN آیکون، بدون مرحلهٔ ساخت — همان یک فایل
- **دسکتاپ:** در عرض بزرگ، منوها به ریل عمودی آیکون‌دار تبدیل می‌شوند و هر کارت منوی «⋯» با خروجی CSV از همان داده دارد

### 📊 داشبورد
- مجموع دارایی به‌صورت زنده از همهٔ حساب‌ها + **تغییر خالص ماه نسبت به ماه قبل**
- نمودار روند خالص ۳۰ روز اخیر
- درآمد و هزینهٔ ماه + نرخ پس‌انداز با نوار پیشرفت
- خلاصهٔ بودجه و آخرین تراکنش‌ها در شبکهٔ Bento

### 💸 تراکنش‌ها
- ثبت، ویرایش و حذف تراکنش
- دسته‌بندی، حساب، روش پرداخت (نقدی، کارت‌خوان، کارت‌به‌کارت و…)
- **محاسبهٔ کارمزد بانکی** و ثبت خودکار آن
- جستجو و فیلتر ترکیبی + گروه‌بندی بر اساس روز

### 🔎 جستجوی سراسری
- یک جای واحد برای پیدا کردن **همه‌چیز**: تراکنش، حساب، شخص، وام، دوره‌ای، دسته و حتی **مبلغ**
- باز شدن با **Ctrl+K** (ویندوز/لینوکس) یا **⌘K** (مک)، یا دکمهٔ 🔍 در نوار بالا
- ناوبری کامل با کیبورد: **↑↓ حرکت · Enter باز کردن · Esc بستن**
- پرش مستقیم: با انتخاب نتیجه، به تب مربوطه می‌رود و آیتم را هایلایت می‌کند
- نرمال‌سازی فارسی: ی/ك عربی، أ/إ/آ و اعداد فارسی/عربی هم پیدا می‌شوند

### ✨ چه چیزهایی جدید است؟
- بعد از هر **به‌روزرسانی**، بار اولی که برنامه باز شود یک مودال خوشامد نشان داده می‌شود:
  - فهرست امکانات تازهٔ نسخه‌های اخیر + **تاریخ انتشار شمسی**
  - فقط یک بار در هر نسخه؛ بعد از بستن دوباره نمایش داده نمی‌شود

### ⏰ تراکنش‌های دوره‌ای
- حقوق، اجاره، اشتراک و… با تکرار **ماهانه، هفتگی یا هر N روز**
- **ثبت خودکار** سررسید‌ها (و دوره‌های جاافتاده) هنگام باز کردن برنامه
- حالت یادآوری با ثبت دستی + کلید خودکار/دستی برای هر قلم

### 🏦 حساب‌ها
- چهار نوع: نقدی، کارت بانکی، کیف الکترونیک، پس‌انداز
- رنگ و آیکون سفارشی + شماره کارت
- نمایش ورودی/خروجی ماهانهٔ هر حساب

### 💰 وام‌ها و اقساط
- تعریف وام با مبلغ قسط، تعداد اقساط و روز سررسید
- نوار پیشرفت اقساط + آمار پرداختی و باقی‌مانده
- **هشدار قسط عقب‌افتاده** و ثبت خودکار تراکنش با یک کلیک

### 🎯 بودجه‌بندی
- سقف ماهانه برای هر دستهٔ هزینه
- حلقهٔ پیشرفت مصرف کل + ویرایش سریع درون‌خطی

### 📈 گزارش‌ها
- دوره‌های هفته، ماه، ماه قبل، ۳ ماه، امسال و کل
- نمودار دونات ترکیب هزینه‌ها + نمودار میله‌ای ۶ ماه اخیر
- تفکیک هزینه بر اساس شخص + بینش‌های خودکار
- **خروجی CSV** با پشتیبانی کامل اکسل فارسی
- **گزارش چاپی / PDF** اندازه A4 (بدون کتابخانه، با چاپگر خود مرورگر)
- **کارت ماهانهٔ اشتراکی** — تصویر ۱۰۸۰×۱۹۲۰ با تراز، پس‌انداز و پرهزینه‌ترین‌ها

### 🗓️ تقویم شمسی
- نمای ماهانه با نشانگر تراکنش‌های هر روز
- خلاصهٔ درآمد/هزینهٔ روز انتخابی

### 🔐 امنیت
- قفل ورود با **پین** (اختیاری — در اولین اجرا تعیین می‌شود)
- **سوال امنیتی** برای بازیابی پین فراموش‌شده (پاسخ هش‌شده ذخیره می‌شود)
- امکان تغییر یا حذف پین از «⚙️ پین و امنیت»

### 💾 پشتیبان‌گیری
- پشتیبان‌گیری خودکار (روزانه / ۳ روز / هفتگی / ماهانه)
- اتصال به فایل ثابت با File System Access API
- بازیابی کامل از فایل JSON

### 📥 واردات از اکسل
- خواندن مستقیم **`.xlsx`** و **`.csv`** در مرورگر — بدون آپلود، بدون سرور، بدون کتابخانه
- پیاده‌سازی خوانندهٔ xlsx روی `DecompressionStream` (unzip) + `DOMParser` (XML)
- ویزارد سه‌مرحله‌ای: **منبع** (فایل / درگ‌اند‌دراپ / چسباندن از کلیپ‌بورد) ← **ستون‌ها** (انتخاب شیت، ردیف سرستون، نقش هر ستون با تشخیص خودکار) ← **پیش‌نمایش**
- تشخیص خودکار نقش ستون‌ها از روی سرستون فارسی/انگلیسی (تاریخ، شرح، مبلغ، برداشت/واریز، واحد، شخص، دسته، حساب)
- نرمال‌سازی تاریخ: **شمسی متنی**، **میلادی**، و **شماره‌تاریخ اکسل** (serial)
- واحد ریال/تومان با انتخاب کاربر یا ستونِ واحد؛ مبالغ منفی و داخل پرانتز هم فهمیده می‌شود
- تفکیک خودکار دستهٔ تراکنش‌ها از روی کلیدواژهٔ شرح (اختیاری)
- **ردیف تکراری خودکار رد می‌شود** (همان تاریخ + مبلغ + شرح) و واردات **جایگزین داده‌های فعلی نمی‌شود، اضافه می‌کند**
- دکمهٔ **بازگردانی آخرین واردات** — کل یک دستهٔ وارداتی را با یک کلیک حذف می‌کند

### 📱 نصب‌پذیر (PWA)
- نصب روی گوشی و دسکتاپ مثل اپلیکیشن واقعی
- کاملاً آفلاین پس از اولین بارگذاری

## 🚀 شروع سریع

### روش اول — با Git
```bash
git clone https://github.com/m38d1/Hesab.git
cd Hesab
```
سپس فایل `index.html` را در مرورگر باز کنید. همین! 🎉

### روش دوم — بدون Git
در صفحهٔ ریپازیتوری: **Code ← Download ZIP** ← استخراج ← باز کردن `index.html`

> 💡 برای تجربهٔ کامل PWA از طریق سرور محلی اجرا کنید:
> ```bash
> npx serve .
> ```

## 🔑 ورود به برنامه

در **اولین اجرا** صفحهٔ شروع می‌پرسد:

| مورد | توضیح |
|---|---|
| پین (اختیاری) | حداقل ۴ رقم؛ اگر خالی بگذارید برنامه بدون قفل باز می‌شود |
| سوال امنیتی | فقط در صورت تنظیم پین، برای بازیابی آن لازم است |

> ⚠️ **امنیت:** این قفل سطح مرورگر است (داده‌ها در همان دستگاه می‌مانند). برای حذف یا تغییر پین: «⚙️ پین و امنیت» در پایین صفحه.

## ❓ سوالات متداول

**داده‌های من کجا ذخیره می‌شوند؟**
فقط در `localStorage` مرورگرِ خودتان. هیچ سروری در کار نیست.

**اگر داده‌های مرورگر را پاک کنم چه می‌شود؟**
داده‌ها از بین می‌روند! حتماً از بخش «پشتیبان‌گیری» فایل JSON بگیرید.

**تومان است یا ریال؟**
هر دو! با یک کلیک از نوار بالا بین تومان و ریال جابجا شوید.
