## 📖 حساب‌وکتاب چیست؟

**حساب‌وکتاب** یک وب‌اپلیکیشن مدیریت مالی شخصی است که به‌طور کامل داخل مرورگر اجرا می‌شود — بدون سرور، بدون دیتابیس، بدون نیاز به اینترنت. تمام داده‌ها فقط در مرورگر خودِ شما ذخیره می‌شوند و هرگز به هیچ سروری ارسال نمی‌شوند.

> ✨ تقویم شمسی (جلالی) به‌صورت الگوریتمی داخل خودِ برنامه پیاده‌سازی شده — بدون هیچ کتابخانهٔ خارجی.

---

## ✨ امکانات

### 📊 داشبورد
- مجموع دارایی به‌صورت زنده از همهٔ حساب‌ها
- نمودار روند خالص ۳۰ روز اخیر
- درآمد و هزینهٔ ماه + نرخ پس‌انداز با نوار پیشرفت
- خلاصهٔ بودجه و آخرین تراکنش‌ها

### 💸 تراکنش‌ها
- ثبت، ویرایش و حذف تراکنش
- دسته‌بندی، حساب، روش پرداخت (نقدی، کارت‌خوان، کارت‌به‌کارت و…)
- **محاسبهٔ کارمزد بانکی** و ثبت خودکار آن
- جستجو و فیلتر ترکیبی + گروه‌بندی بر اساس روز

### 🏦 حساب‌ها
- چهار نوع: نقدی، کارت بانکی، کیف الکترونیک، پس‌انداز
- رنگ و آیکون سفارشی + شماره کارت
- نمایش ورودی/خروجی ماهانهٔ هر حساب

### 💰 وام‌ها و اقساط
- تعریف وام با مبلغ قسط، تعداد اقساط و روز سررسید
- نوار پیشرفت اقساط + آمار پرداختی و باقی‌مانده
- **هشدار قسط عقب‌افتاده** و ثبت خودکار تراکنش با یک کلیک

### 🎯 بودجه‌بندی
- سقف ماهانه برای هر دستهٔ هزینه
- حلقهٔ پیشرفت مصرف کل + ویرایش سریع درون‌خطی

### 📈 گزارش‌ها
- دوره‌های هفته، ماه، ماه قبل، ۳ ماه، امسال و کل
- نمودار دونات ترکیب هزینه‌ها + نمودار میله‌ای ۶ ماه اخیر
- تفکیک هزینه بر اساس شخص + بینش‌های خودکار
- **خروجی CSV** با پشتیبانی کامل اکسل فارسی

### 🗓️ تقویم شمسی
- نمای ماهانه با نشانگر تراکنش‌های هر روز
- خلاصهٔ درآمد/هزینهٔ روز انتخابی

### 🔐 امنیت
- ورود با نام کاربری و رمز عبور
- **سوال امنیتی** برای بازیابی رمز فراموش‌شده
- امکان تغییر رمز و سوال امنیتی

### 💾 پشتیبان‌گیری
- پشتیبان‌گیری خودکار (روزانه / ۳ روز / هفتگی / ماهانه)
- اتصال به فایل ثابت با File System Access API
- بازیابی کامل از فایل JSON

### 📱 نصب‌پذیر (PWA)
- نصب روی گوشی و دسکتاپ مثل اپلیکیشن واقعی
- کاملاً آفلاین پس از اولین بارگذاری

## 🚀 شروع سریع

### روش اول — با Git
```bash
git clone https://github.com/USERNAME/hesabketab.git
cd hesabketab
```
سپس فایل `index.html` را در مرورگر باز کنید. همین! 🎉

### روش دوم — بدون Git
در صفحهٔ ریپازیتوری: **Code ← Download ZIP** ← استخراج ← باز کردن `index.html`

> 💡 برای تجربهٔ کامل PWA از طریق سرور محلی اجرا کنید:
> ```bash
> npx serve .
> ```

## ❓ سوالات متداول

**داده‌های من کجا ذخیره می‌شوند؟**
فقط در `localStorage` مرورگرِ خودتان. هیچ سروری در کار نیست.

**اگر داده‌های مرورگر را پاک کنم چه می‌شود؟**
داده‌ها از بین می‌روند! حتماً از بخش «پشتیبان‌گیری» فایل JSON بگیرید.

**تومان است یا ریال؟**
هر دو! با یک کلیک از نوار بالا بین تومان و ریال جابجا شوید.
